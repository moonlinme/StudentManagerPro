# 委托实现窗体定向通信：A → B → C → A

## 需求

- 三个窗体：主窗体 A、B、C
- A 输入信息，传给 B
- B 接收到后，传给 C
- C 输入数据（**不包括 B 传入的数据**），只能传给 A
- **A、B、C 界面采用同一个类**

## 核心思路

| 要点 | 做法 |
|------|------|
| 同一个类出三个窗体 | `new FrmData(...)` 三次，靠**实例**区分 A/B/C |
| 定向传递（不广播） | 每个实例持有一个**实例委托** `SendTo`，指向"下家"的接收方法 |
| B 收到后自动转给 C | 给 B 开 `AutoForward` 开关，收到数据后立刻经 `SendTo` 转发 |
| C 只传自己的输入 | C 的 `SendTo` 只指向 A，且发送时发自己输入框的内容 |

**不用静态、不用全局**：委托是实例字段，每个窗体各一份，接线在局部完成。

## 代码实现

### 1. 共用窗体类 [FrmData.cs](../StudentManagerPro/FrmData.cs)

```csharp
// 委托：约定"发数据"的形状（接收一个 string）
public delegate void DataHandler(string data);

public class FrmData : Form
{
    // 界面控件（代码创建，A/B/C 长得一样）
    private TextBox txtInput = new TextBox();
    private Button btnSend = new Button();
    private Label lblShow = new Label();

    // 发送通道：指向"下家"的接收方法（实例委托，非静态）
    public DataHandler SendTo;

    // 收到数据后是否自动转发给下家（只有 B 设为 true）
    public bool AutoForward = false;

    // 接收数据：先显示；若开了自动转发，立刻把数据继续传给下家
    public void ReceiveData(string data)
    {
        lblShow.Text = "收到: " + data;

        if (AutoForward && SendTo != null)   // 判空：没接下家时不报错
        {
            SendTo(data);                    // 调自己的 SendTo = 下家的 ReceiveData
        }
    }

    // 点发送：把自己的输入定向发给下家（判空）
    private void btnSend_Click(object sender, EventArgs e)
    {
        if (SendTo != null)
        {
            SendTo(txtInput.Text);
        }
    }
}
```

两个方向要分清：

- `ReceiveData` 是**入口**：被别人（上家）调用的
- `SendTo` 是**出口**：自己去调别人（下家）的

### 2. 接线（[Program.cs](../StudentManagerPro/Program.cs) 的 `StartDemo()`）

```csharp
public static void StartDemo()
{
    // 1. 同一个类 new 出三个独立窗体实例
    FrmData A = new FrmData("A 主窗体");
    FrmData B = new FrmData("B 窗体");
    FrmData C = new FrmData("C 窗体");

    // 2. 接线：把"下家的接收方法"挂到"自己的发送委托"上，形成 A→B→C→A 的环
    //    接线本身不发数据，只是约定好"以后我发送时，谁来收"
    A.SendTo = B.ReceiveData;   // A 发送 = 执行 B.ReceiveData（A 发 → B 收）
    B.SendTo = C.ReceiveData;   // B 发送 = 执行 C.ReceiveData（B 发/转发 → C 收）
    C.SendTo = A.ReceiveData;   // C 发送 = 执行 A.ReceiveData（C 发 → 只回 A）

    // 3. 只有 B 开启"收到后自动转发"：B 一收到 A 的数据，立刻经 SendTo 转给 C
    B.AutoForward = true;

    // 4. 显示三个窗体：B、C 非模态弹出，A 作为主窗体启动消息循环
    B.Show();
    C.Show();
    Application.Run(A);
}
```

## 数据流

```
A 输入"张三" 点发送
  └→ A.SendTo("张三")  =  B.ReceiveData("张三")
       ├→ B 显示"收到: 张三"
       └→ B.AutoForward=true → B.SendTo("张三")  =  C.ReceiveData("张三")
            └→ C 显示"收到: 张三"（C 不转发，停）

C 输入"李四" 点发送
  └→ C.SendTo("李四")  =  A.ReceiveData("李四")
       └→ A 显示"收到: 李四"（A 不转发，停）
```

## 关键概念速记

1. **委托字段 = 存方法引用的变量**。`A.SendTo = B.ReceiveData` 是把 B 的方法引用塞进 A 的变量（注意 `ReceiveData` 没括号，是取引用不是调用），方法体还在 B 身上，没有复制。
2. **谁调用委托，谁发数据；谁提供符合签名的方法，谁收数据**。
3. **每个实例各有一份 `SendTo`**：`ReceiveData` 里的 `SendTo` 是"我自己的出口"，判空是防止没接线时抛出 `NullReferenceException`。
4. **定向 vs 广播**：实例委托一对一、指向明确；要广播才需要静态事件/消息中心。本场景是定向传递，实例委托是最省、最安全的做法。
