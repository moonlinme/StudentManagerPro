## 项目架构

### 整体结构：经典三层架构

```
┌─────────────────────────────────────┐
│  StudentManagerPro (UI 层)          │
│  - WinForms 桌面应用 (.NET 4.0)     │
│  - 登录窗体 → 主窗体                 │
│  - 直接引用 DAL 和 Models            │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│  DAL (数据访问层)                   │
│  - SQLHelper: 通用 SQL 执行工具      │
│  - StudentService: 学生 CRUD        │
│  - StudentClassService: 班级查询    │
│  - SysAdminService: 管理员登录      │
│  - 引用 Models                       │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│  Models (模型层)                    │
│  - Student, StudentClass            │
│  - SysAdmin, ScoreList(空)          │
│  - 纯 POCO，无依赖                   │
└─────────────────────────────────────┘
```

### 项目详情

| 项目                  | 类型                | 说明                      |
| --------------------- | ------------------- | ------------------------- |
| **StudentManagerPro** | WinForms (.NET 4.0) | 主程序，入口 `Program.cs` |
| **DAL**               | Class Library       | 数据访问，依赖 Models     |
| **Models**            | Class Library       | 实体模型，无外部依赖      |

### 数据模型

### 技术特点

- **SQL 拼接方式**：所有 SQL 直接字符串拼接，存在 SQL 注入风险
- **无 ORM**：纯 ADO.NET (`SqlConnection`, `SqlCommand`, `SqlDataReader`)
- **无依赖注入**：各层直接实例化使用
- **缺少 BLL 层**：业务逻辑直接写在 DAL Service 或 UI 层
